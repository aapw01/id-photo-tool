# Pixfit 报告问题整改清单

> 建立日期：2026-11-14<br>
> 项目：`pix-fit.com` / `/Users/xiao/Developer/id-photo-tool`<br>
> 当前分支：`feat/seo-remediation`<br>
> 当前阶段：代码整改已完成，等待预览、上线和搜索引擎重新抓取

这份清单只处理项目内部能够安全完成的 SEO 配置和 metadata 文案。整改以真实搜索意图和用户任务为依据，不为了单一 CTR 指标堆砌关键词。

## 范围边界

本次纳入：

- Bing 报告中的 Meta description 过短问题
- Bing 报告中的标题过长问题
- 高曝光低点击词对应的页面标题和摘要核对
- IndexNow 的项目内配置与手动提交工具
- Bing、GA4、Vercel Analytics 的数据口径说明

明确不纳入：

- 本地 AI 抠图、MODNet、ONNX Runtime、ROI、WASM 多线程、COOP/COEP、模型资源和 alpha 后处理
- 前端布局、视觉设计、交互流程、业务逻辑和转化漏斗
- 高质量入站链接建设、外部网站联系和站外推广
- 广告脚本、广告位设计和收益优化

高质量入站链接不足属于站外运营事项，不能通过仓库代码“修复”，本次不做。IndexNow 只能加快 Bing 发现更新，不能代替外链建设，也不能保证排名或 CTR 上升。

## 已确认的数据基线

- Bing 按天概览：353,043 次曝光、13,210 次点击，整体 CTR 约 3.74%。
- Bing 关键词报告：2,607 个关键词、180,870 次曝光、7,214 次点击；与按天概览不是同一统计口径，不能相加。
- 关键词报告有 52 行 CTR 超过 100% 的异常数据，包含 URL、Markdown 链接和其他非标准查询词，分析时必须单独排除。
- 高曝光低点击词包括“一寸照片尺寸”“身份证照片”“2寸照片尺寸”“一寸照片像素”“证件照压缩”等；低 CTR 只能说明搜索结果点击表现弱，不能直接证明页面功能有问题。
- 国家报告中中国点击约占 82.2%，美国约占 4.4%，`ww` 约占 9.6%；`ww` 不能直接按某个国家的广告单价估算。
- GA4 已收到上传、抠图、导出、扫描等事件，但 referrer 只能说明来源，不能还原 Bing 用户输入的具体搜索词；搜索词以 Bing Webmaster Tools 为准。
